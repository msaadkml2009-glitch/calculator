## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root). The site is static HTML, CSS and JavaScript, so it works on GitHub Pages with no build step.

## Notes

- Fun calculators (love, crush, soulmate, marriage, angel numbers, moon sign) are for entertainment only.
- Finance and health calculators are estimates, not professional advice.
- Moon sign is approximate; exact moon signs need precise birth time, location and an ephemeris.
